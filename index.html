Setup Completo do Zero

Do Windows pelado ao terminal turbinado. Segue a ordem, não pula etapa.

01

Base — PowerShell 7 + Terminal

Substitui o PowerShell 5.1 jurássico que vem no Windows

1.1 Instalar o PowerShell 7▶

O PowerShell que vem no Windows (5.1) é antigo e limitado. O 7+ é cross-platform, mais rápido e compatível com tudo que vamos instalar.

❯ winget install Microsoft.PowerShell
ℹDepois de instalar, você terá dois PowerShells: "Windows PowerShell" (5.1, antigo) e "PowerShell" (7+, novo). Sempre use o novo.

Verificar:

❯ $PSVersionTable.PSVersion

Tem que retornar 7.x.x.

🔗 GitHub
1.2 Instalar o Windows Terminal▶

Terminal moderno da Microsoft com abas, split panes, GPU rendering e suporte a fontes Nerd Font.

❯ winget install Microsoft.WindowsTerminal
⚠Se já veio instalado no seu Windows 11, pule este passo.
🔗 GitHub
1.3 Mudar perfil padrão para PowerShell 7▶

Faz o Windows Terminal abrir o PowerShell 7 por padrão em vez do 5.1.

  • Abre o Windows Terminal
  • Ctrl+, → Settings
  • Startup → Default profile → seleciona "PowerShell" (o novo, não "Windows PowerShell")
  • Salva
1.4 Liberar Execution Policy▶

Permite que o PowerShell execute scripts (necessário pro profile e módulos).

❯ Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
ℹSó precisa fazer isso uma vez. RemoteSigned é seguro: permite scripts locais e exige assinatura em scripts baixados.
02

Visual — Fonte, Tema e Prompt

Deixa o terminal bonito antes de configurar funcionalidades

2.1 Instalar Nerd Font▶

Sem Nerd Font, os ícones do Oh My Posh e do Terminal-Icons aparecem como quadradinhos □□□.

# Instala via Oh My Posh (mais fácil) ❯ oh-my-posh font install JetBrainsMono
⚠Se o Oh My Posh ainda não tiver instalado (próximo passo), baixe manualmente em nerdfonts.com. Recomendo JetBrains Mono Nerd Font ou FiraCode Nerd Font.

Configurar no Windows Terminal:

  • Ctrl+, → Settings
  • Profiles → Defaults → Appearance → Font face
  • Seleciona JetBrainsMono Nerd Font
  • Salva
🔗 Nerd Fonts
2.2 Instalar Oh My Posh▶

Theme engine que transforma o prompt com informações de git, tempo de execução, erros, segmentos coloridos.

❯ winget install JanDeDobbeleer.OhMyPosh

Fecha e abre o terminal pra ele reconhecer o oh-my-posh no PATH.

Verificar:

❯ oh-my-posh version
🔗 ohmyposh.dev 🎨 Temas
2.3 Baixar os temas do Oh My Posh▶

Se instalou via Microsoft Store (ou os temas não vieram), precisa baixar separado.

# Cria a pasta de temas ❯ New-Item -Path "$env:LOCALAPPDATA\Programs\oh-my-posh\themes" -ItemType Directory -Force # Baixa todos os temas ❯ Invoke-WebRequest -Uri "https://github.com/JanDeDobbeleer/oh-my-posh/releases/latest/download/themes.zip" -OutFile "$env:TEMP\omp-themes.zip" # Extrai ❯ Expand-Archive -Path "$env:TEMP\omp-themes.zip" -DestinationPath "$env:LOCALAPPDATA\Programs\oh-my-posh\themes" -Force # Confirma (deve retornar 80+) ❯ (Get-ChildItem "$env:LOCALAPPDATA\Programs\oh-my-posh\themes" -Filter "*.omp.json").Count
ℹSe instalou via winget e os temas já estão lá, pule este passo. Teste com $env:POSH_THEMES_PATH — se retornar um caminho com arquivos, tá ok.
03

Módulos PowerShell

Completação, fuzzy finder, ícones e git integration

3.1 Instalar fzf (dependência do PSFzf)▶

Binário do fuzzy finder. Sem ele, o módulo PSFzf não funciona.

❯ winget install junegunn.fzf

Fecha e abre o terminal. Verifica:

❯ fzf --version
🔗 GitHub
3.2 Instalar módulos do PowerShell▶

Roda tudo de uma vez:

❯ Install-Module -Name PSReadLine -Force -SkipPublisherCheck ❯ Install-Module -Name PSFzf -Force ❯ Install-Module -Name Terminal-Icons -Force ❯ Install-Module -Name posh-git -Force ❯ Install-Module -Name ZLocation -Force
ℹSe pedir confirmação de repositório não confiável (PSGallery), digita Y.

O que cada um faz:

  • PSReadLine — completação Tab, histórico preditivo, syntax highlighting
  • PSFzf — Ctrl+R (histórico fuzzy), Ctrl+T (busca arquivos)
  • Terminal-Icons — ícones coloridos nos arquivos
  • posh-git — branch no prompt + tab completion de branches
  • ZLocation — pula pra diretórios frequentes com z nome
PSReadLine PSFzf Terminal-Icons posh-git ZLocation

Ferramentas CLI Modernas

Substituem comandos antigos por versões mais rápidas e bonitas

4.1 CLI modernas via winget▶

Roda tudo de uma vez:

# Substitui cat ❯ winget install sharkdp.bat # Substitui ls ❯ winget install eza-community.eza # Substitui grep (10x mais rápido) ❯ winget install BurntSushi.ripgrep # Substitui find ❯ winget install sharkdp.fd # Substitui man (resumos práticos) ❯ winget install tldr-pages.tlrc # Processar JSON ❯ winget install jqlang.jq # git diff bonito (lado a lado) ❯ winget install dandavison.delta

Fecha e abre o terminal depois de instalar tudo. Verifica:

❯ bat --version ❯ eza --version ❯ rg --version ❯ fd --version ❯ tldr --version ❯ jq --version ❯ delta --version
bat eza ripgrep fd tldr jq delta
4.2 Configurar delta como pager do git▶

Faz o git diff e git log usarem delta automaticamente:

❯ git config --global core.pager delta ❯ git config --global interactive.diffFilter "delta --color-only" ❯ git config --global delta.navigate true ❯ git config --global delta.side-by-side true
✔Agora todo git diff, git show e git log -p mostra diff lado a lado com syntax highlighting.

Infra & Database

PostgreSQL, scanner de rede, DNS, traceroute

6.1 Ferramentas de rede▶
# Ping gráfico (múltiplos hosts) ❯ winget install orf.gping # DNS lookup moderno ❯ winget install mr-karan.doggo # Scanner de rede ❯ winget install Insecure.Nmap
⚠O nmap instala o Npcap junto (driver de captura de pacotes). Aceite a instalação do Npcap quando aparecer.

Testa:

❯ gping google.com 8.8.8.8 1.1.1.1 ❯ doggo google.com A MX ❯ nmap -sP 192.168.1.0/24
gping doggo nmap
6.2 WinMTR (traceroute visual) — .exe avulso▶

Não tem no winget. Baixa o .exe e joga na pasta bin.

1. Baixa o WinMTR-v100-static.zip (versão estática, sem dependências):

⬇ Download

2. Cria a pasta bin e extrai:

# Cria pasta pra .exe avulsos ❯ New-Item -ItemType Directory -Path "$env:LOCALAPPDATA\bin" -Force # Extrai ❯ Expand-Archive "$env:USERPROFILE\Downloads\WinMTR-v100-static.zip" -DestinationPath "$env:TEMP\winmtr" # Descobre onde está o .exe ❯ Get-ChildItem "$env:TEMP\winmtr" -Recurse -Filter "*.exe" # Copia a versão 64-bit ❯ Copy-Item "$env:TEMP\winmtr\WinMTR64.exe" "$env:LOCALAPPDATA\bin\winmtr.exe"

3. Adiciona a pasta bin no PATH (só precisa fazer uma vez):

❯ [Environment]::SetEnvironmentVariable("Path", "$env:LOCALAPPDATA\bin;" + [Environment]::GetEnvironmentVariable("Path", "User"), "User")

Fecha e abre o terminal. Testa:

❯ winmtr
ℹA pasta $env:LOCALAPPDATA\bin serve pra qualquer .exe avulso. Joga lá e já funciona como comando.
6.3 pgcli & usql (PostgreSQL / SQL)▶

Requer Python instalado.

⚠Se der erro de permissão, adiciona --user no final. Se pedir --break-system-packages, adiciona também.

Uso:

# pgcli ❯ pgcli -h servidor -U usuario -d banco # usql ❯ usql pg://user:pass@host/db
pgcli usql
07

Profile — Juntando Tudo

O arquivo que carrega toda a configuração quando o terminal abre

7.1 Criar / editar o profile▶

Abre o arquivo do profile:

❯ notepad $PROFILE

Se der erro dizendo que o arquivo não existe:

❯ New-Item -Path $PROFILE -ItemType File -Force ❯ notepad $PROFILE

Cola o profile completo abaixo, salva e fecha o notepad.

Troubleshooting

Quando der merda (e vai dar, é Windows)

! CONFIG NOT FOUND▶

A variável $env:POSH_THEMES_PATH tá vazia ou o tema não existe.

Fix: Certifique-se que essa linha está antes do oh-my-posh init no profile:

$env:POSH_THEMES_PATH = "$env:LOCALAPPDATA\Programs\oh-my-posh\themes"

Se a pasta está vazia, volte ao passo 2.3 e baixe os temas.

! Ícones aparecem como □□□▶

Nerd Font não está configurada no Windows Terminal.

Fix: Settings → Profiles → Defaults → Appearance → Font face → JetBrainsMono Nerd Font

⬇ Baixar fontes
! Ctrl+R não faz nada▶

O binário fzf não está instalado. PSFzf depende dele.

❯ winget install junegunn.fzf

Fecha e abre o terminal.

! Comando não reconhecido após winget install▶

O PATH ainda não foi atualizado na sessão atual.

Fix: Fecha e abre o terminal. Se persistir, verifica se instalou mesmo:

❯ winget list nome-do-pacote
! Terminal demora mais de 2s pra abrir▶

Muitos módulos carregando. Mede o tempo:

❯ Measure-Command { . $PROFILE }

Comenta módulos um por um no profile até achar o culpado. Geralmente é um módulo que não instalou ou está corrompido.

! .exe avulso não roda▶

O .exe não está no PATH. Joga em $env:LOCALAPPDATA\bin e certifica que a pasta está no PATH:

❯ $env:Path -split ";" | Select-String "bin"

Se não aparecer, adiciona:

❯ [Environment]::SetEnvironmentVariable("Path", "$env:LOCALAPPDATA\bin;" + [Environment]::GetEnvironmentVariable("Path", "User"), "User")
